# NIRDHOOM — ਖੇਤ-ਕੇਂਦਰਿਤ ਨੈੱਟਵਰਕ (V7)

<p align="center"><img src="public/images/punjab_farm_hero.jpg" alt="ਪੰਜਾਬ ਦੇ ਖੇਤ" width="100%"></p>

**NIRDHOOM** ਫ਼ਸਲੀ ਰਹਿੰਦ-ਖੂੰਹਦ ਦੇ ਪ੍ਰਬੰਧਨ ਲਈ ਕਿਸਾਨ-ਕੇਂਦਰਿਤ ਨੈੱਟਵਰਕ ਦਾ ਪ੍ਰੋਟੋਟਾਈਪ ਹੈ। ਇਸਦਾ ਮਕਸਦ ਖੇਤ, ਕਿਸਾਨ ਦੀ ਸਹਿਮਤੀ, ਬੁਕਿੰਗ, ਮਸ਼ੀਨ ਡਿਸਪੈਚ, ਕੰਮ ਦੇ ਸਬੂਤ, ਰਹਿੰਦ-ਖੂੰਹਦ ਦੀ ਵਿਕਰੀ ਅਤੇ ਭੁਗਤਾਨ ਰਿਕਾਰਡ ਨੂੰ ਇੱਕ ਪ੍ਰਕਿਰਿਆ ਵਿੱਚ ਜੋੜਨਾ ਹੈ।

> **ਮੌਜੂਦਾ ਸਥਿਤੀ:** ਇਹ V7 ਵਿਕਾਸ ਅਧੀਨ ਪ੍ਰੋਜੈਕਟ ਹੈ। ਡੈਮੋ ਡਾਟਾ, ਅੰਦਾਜ਼ਨ ਕੀਮਤਾਂ ਅਤੇ ਹੀਯੂਰਿਸਟਿਕ ਡਿਸਪੈਚ ਅਸਲ ਸੇਵਾ ਜਾਂ ਭੁਗਤਾਨ ਦਾ ਸਬੂਤ ਨਹੀਂ ਹਨ।

## ਇਸ ਵਰਜਨ ਵਿੱਚ

- ਕਿਸਾਨ: ਹੋਮ, ਖੇਤ, ਹੱਦ ਖਿੱਚਣ ਦਾ ਪ੍ਰੋਟੋਟਾਈਪ, ਕਲੀਅਰੈਂਸ ਬੁਕਿੰਗ ਅਤੇ ਟਾਈਮਲਾਈਨ
- ਆਪਰੇਟਰ: ਅਸਾਈਨਮੈਂਟ ਤੋਂ ਕੰਮ ਮੁਕੰਮਲ ਹੋਣ ਤੱਕ ਜੌਬ ਫ਼ਲੋ ਅਤੇ ਆਫ਼ਲਾਈਨ ਸਬੂਤ ਕਤਾਰ
- ਡਿਸਪੈਚ: ਡੈੱਡਲਾਈਨ ਕਤਾਰ ਅਤੇ ਫਲੀਟ ਦ੍ਰਿਸ਼; ਆਪਟੀਮਾਈਜ਼ਰ ਨਾਲ ਜੋੜ ਵਿਕਲਪਿਕ
- ਤਸਦੀਕ: ਖੇਤ, ਸਬੂਤ ਅਤੇ ਰਿਮੋਟ-ਸੈਂਸਿੰਗ ਆਡਿਟ ਮਾਡਲ
- ਰਹਿੰਦ-ਖੂੰਹਦ: ਖਰੀਦਦਾਰ ਪੇਸ਼ਕਸ਼ਾਂ ਅਤੇ ਲਾਟ/ਕਾਰਬਨ ਰਿਕਾਰਡ ਦਾ ਆਧਾਰ
- NIRDHOOM Sathi: ਸੰਦਰਭ-ਅਧਾਰਿਤ ਸਹਾਇਕ UI
- Supabase ਸਾਈਨ-ਇਨ ਅਤੇ PWA ਐਪ-ਸ਼ੈੱਲ ਦਾ ਆਧਾਰ

## ਆਪਣੇ ਕੰਪਿਊਟਰ ਉੱਤੇ ਚਲਾਓ

Node.js 24.x ਲੋੜੀਂਦਾ ਹੈ।

```bash
npm install
npm run dev
```

ਜਾਂਚ ਅਤੇ ਬਿਲਡ:

```bash
npm run syntaxcheck
npm run test
npm run audit
npm run build
npm run e2e
```

ਮੌਜੂਦਾ ਬ੍ਰਾਊਜ਼ਰ ਐਪ `src/main.jsx` ਤੋਂ ਸ਼ੁਰੂ ਹੁੰਦੀ ਹੈ। `src/main.tsx` / `src/App.tsx` ਵੱਖਰੀ TypeScript ਐਪ ਹੈ ਅਤੇ ਮੌਜੂਦਾ ਬ੍ਰਾਊਜ਼ਰ ਐਂਟਰੀ ਨਹੀਂ ਹੈ।

## Supabase ਸੈੱਟਅੱਪ

1. NIRDHOOM ਲਈ ਵੱਖਰਾ Supabase ਪ੍ਰੋਜੈਕਟ ਬਣਾਓ; ਕਿਸੇ ਹੋਰ ਪ੍ਰੋਜੈਕਟ ਨੂੰ ਮੁੜ ਨਾ ਵਰਤੋ।
2. `supabase/migrations/` ਵਿੱਚ 001, 002, 003 ਅਤੇ 004 ਮਾਈਗ੍ਰੇਸ਼ਨ ਇਸੇ ਕ੍ਰਮ ਵਿੱਚ ਚਲਾਓ।
3. ਡੈਮੋ ਡਾਟਾ ਲਈ ਚਾਹੋ ਤਾਂ `supabase/seed.sql` ਚਲਾਓ।
4. `.env.example` ਨੂੰ `.env.local` ਵਿੱਚ ਕਾਪੀ ਕਰੋ।
5. `VITE_SUPABASE_URL` ਅਤੇ ਬ੍ਰਾਊਜ਼ਰ-ਸੁਰੱਖਿਅਤ publishable key ਹੀ ਕਲਾਇੰਟ ਵਿੱਚ ਰੱਖੋ। Service-role key ਸਿਰਫ਼ ਸਰਵਰ ਉੱਤੇ ਰਹੇ।

## ਹਾਲੇ ਲੋੜੀਂਦੇ ਅਸਲ ਇੰਟੀਗ੍ਰੇਸ਼ਨ

- ਫ਼ੋਨ OTP, WhatsApp ਆਨਬੋਰਡਿੰਗ ਅਤੇ ਸਹਿਮਤੀ/ਵਾਪਸੀ
- ਤਸਦੀਕਸ਼ੁਦਾ Khasra/ਕੈਡਸਟ੍ਰਲ ਖੇਤ ਹੱਦਾਂ
- ਆਪਰੇਟਰ ਦਾ ਲਾਈਵ GPS ਅਤੇ ਨਿੱਜੀ ਫੋਟੋ ਸਟੋਰੇਜ
- ਅਸਲ ਸਮਰੱਥਾ ਅਤੇ OR-Tools ਡਿਸਪੈਚ ਸੇਵਾ
- ਭੁਗਤਾਨ ਪ੍ਰਦਾਤਾ ਅਤੇ ਵੈਬਹੁੱਕ ਮਿਲਾਨ
- ਖਰੀਦਦਾਰ ਇਕਰਾਰਨਾਮੇ, ਪੇਸ਼ਕਸ਼ਾਂ ਅਤੇ ਅਸਲ ਸੈਟਲਮੈਂਟ
- ਰਿਮੋਟ-ਸੈਂਸਿੰਗ ਤਸਦੀਕ, ਨਿਗਰਾਨੀ, ਦਰ-ਸੀਮਾ ਅਤੇ ਪਰਦੇਦਾਰੀ ਨੀਤੀਆਂ
- ਇਕਾਈ, ਇੰਟੀਗ੍ਰੇਸ਼ਨ, RLS ਅਤੇ E2E ਟੈਸਟ

## ਸੁਰੱਖਿਆ ਅਤੇ ਡਾਟਾ

ਆਪਣੇ ਹੱਥ ਨਾਲ ਖਿੱਚੀ ਹੱਦ ਨੂੰ ਕੈਡਸਟ੍ਰਲ ਤੌਰ ’ਤੇ ਤਸਦੀਕਸ਼ੁਦਾ ਨਾ ਦਿਖਾਓ। FIRMS ਦੀ ਅੱਗ-ਸਬੰਧੀ ਪਛਾਣ ਖੇਤ ਸਾਫ਼ ਹੋਣ ਦਾ ਸਬੂਤ ਨਹੀਂ। ਡੈਮੋ ਕਿਸਾਨ/ਮਸ਼ੀਨ/ਖਰੀਦਦਾਰ ਰਿਕਾਰਡ ਅਸਲ ਕਾਰੋਬਾਰੀ ਡਾਟਾ ਨਹੀਂ ਹਨ। ਭੁਗਤਾਨ ਨੂੰ ਪੂਰਾ ਤਦ ਹੀ ਦਿਖਾਓ ਜਦੋਂ ਪ੍ਰਦਾਤਾ ਵੱਲੋਂ ਤਸਦੀਕ ਹੋਵੇ।

## ਯੋਗਦਾਨ

ਬਦਲਾਅ ਤੋਂ ਪਹਿਲਾਂ ਸੰਬੰਧਿਤ ਕੋਡ, ਮਾਈਗ੍ਰੇਸ਼ਨ ਅਤੇ ਟੈਸਟ ਪੜ੍ਹੋ। ਕਮਾਂਡਾਂ, ਫ਼ਾਈਲ ਪਾਥ, API ਨਾਂ ਅਤੇ ਤਕਨੀਕੀ identifiers ਦਾ ਅਨੁਵਾਦ ਨਾ ਕਰੋ। ਬਦਲਾਅ ਤੋਂ ਬਾਅਦ ਉੱਪਰ ਦਿੱਤੀਆਂ ਜਾਂਚਾਂ ਚਲਾਓ।
