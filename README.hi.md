# NIRDHOOM — खेत-केंद्रित नेटवर्क (V7)

<p align="center"><a href="README.md">English</a> · <b>हिन्दी</b> · <a href="README.pa.md">ਪੰਜਾਬੀ</a></p>

<p align="center"><img src="public/images/punjab_farm_hero.jpg" alt="पंजाब के खेत" width="100%"></p>

**NIRDHOOM** फसल-अवशेष प्रबंधन के लिए किसान-केंद्रित नेटवर्क का प्रोटोटाइप है। इसका उद्देश्य खेत, किसान की सहमति, बुकिंग, मशीन डिस्पैच, काम के प्रमाण, अवशेष की बिक्री और भुगतान रिकॉर्ड को एक प्रक्रिया में जोड़ना है।

> **स्थिति:** यह V7 विकासाधीन प्रोजेक्ट है। डेमो डेटा, अनुमानित कीमतें और हीयूरिस्टिक डिस्पैच वास्तविक सेवा या भुगतान का प्रमाण नहीं हैं।

## इस संस्करण में

- किसान: होम, खेत, सीमा-ड्रॉइंग प्रोटोटाइप, क्लियरेंस बुकिंग और टाइमलाइन
- ऑपरेटर: असाइनमेंट से काम पूरा होने तक जॉब फ्लो और ऑफलाइन प्रूफ कतार
- डिस्पैच: डेडलाइन कतार और फ्लीट दृश्य; ऑप्टिमाइज़र कनेक्शन वैकल्पिक
- सत्यापन: खेत, साक्ष्य और रिमोट-सेंसिंग ऑडिट मॉडल
- अवशेष: खरीदार ऑफर और लॉट/कार्बन रिकॉर्ड के लिए आधार
- NIRDHOOM Sathi: संदर्भ-आधारित सहायक UI
- Supabase साइन-इन और PWA ऐप-शेल का आधार

## स्थानीय रूप से चलाएँ

Node.js 24.x आवश्यक है।

```bash
npm install
npm run dev
```

जाँच और बिल्ड:

```bash
npm run syntaxcheck
npm run test
npm run audit
npm run build
npm run e2e
```

ब्राउज़र में वर्तमान सक्रिय ऐप `src/main.jsx` से शुरू होता है। `src/main.tsx` / `src/App.tsx` अलग TypeScript ऐप है और वर्तमान ब्राउज़र एंट्री नहीं है।

## Supabase सेटअप

1. NIRDHOOM के लिए अलग Supabase प्रोजेक्ट बनाएँ; किसी असंबंधित प्रोजेक्ट का उपयोग न करें।
2. `supabase/migrations/` में 001, 002, 003 और 004 माइग्रेशन क्रम से चलाएँ।
3. वैकल्पिक डेमो डेटा के लिए `supabase/seed.sql` चलाएँ।
4. `.env.example` को `.env.local` में कॉपी करें।
5. केवल `VITE_SUPABASE_URL` और ब्राउज़र-सुरक्षित publishable key को क्लाइंट में रखें। Service-role key केवल सर्वर पर रहे।

## अभी आवश्यक वास्तविक इंटीग्रेशन

- फोन OTP, WhatsApp ऑनबोर्डिंग और सहमति/वापसी
- सत्यापित Khasra/कैडस्ट्रल खेत सीमाएँ
- ऑपरेटर का लाइव GPS और निजी फोटो स्टोरेज
- वास्तविक क्षमता और OR-Tools डिस्पैच सेवा
- भुगतान प्रदाता और वेबहुक मिलान
- खरीदार अनुबंध, ऑफर और वास्तविक सेटलमेंट
- रिमोट-सेंसिंग सत्यापन, मॉनिटरिंग, दर-सीमा और गोपनीयता नीतियाँ
- एकीकृत यूनिट, इंटीग्रेशन, RLS और E2E परीक्षण

## सुरक्षा और डेटा

किसी स्वयं-खींची गई सीमा को कैडस्ट्रल सत्यापित न मानें। FIRMS की आग-संबंधी पहचान खेत साफ़ होने का प्रमाण नहीं है। डेमो किसान/मशीन/खरीदार रिकॉर्ड वास्तविक परिचालन डेटा नहीं हैं। भुगतान को तभी पूरा दिखाएँ जब प्रदाता से उसका सत्यापन हो।
